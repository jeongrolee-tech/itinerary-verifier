# 정답 문제 — 회귀셋 37건

정답은 판정 코드의 출력을 보지 않고 공식 페이지 문구에서 만들었다. T16\~T33은 결과를 보지 않은 시험용 문제다 — 2026-10-06 · 10-07 · 10-14에
Claude가 초안을 쓰고 사용자가 확인한 뒤, 처음 돌리기 전에 커밋했다. 초안을 쓴 Claude는 판정 코드를 함께 고쳐 온 쪽이라
코드를 모르는 상태가 아니다. 그래서 정답은 코드가 아니라 [판정 규칙](판정-규칙.md)과 공식 근거로 정했고, 새 18건은 정답을 커밋하기
전에 코드로 돌리거나 결과를 본 적이 없다. T34 · T35는 새 평가(정답을 사람이 먼저 정한 문제)에서 첫 결과를 본 뒤
판정 코드를 고치고 옮긴 연습용 문제다([새 평가 첫 실행](experiments/2026-10-23-new-eval-first-run.md)).
