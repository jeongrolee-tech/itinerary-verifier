## N03 — 꼭 타야 하는 열차의 시각을 모름

> 11월 19일 목요일이에요. 오후 2시에 창덕궁 들어가서 한 시간 반 보고, 4시에 덕수궁에서 한 시간 볼게요. 그다음 서울역에서
> KTX를 꼭 타야 하는데 기차 시간은 아직 안 정했어요.

**입력을 하나 바꿨다** — 창덕궁 → 덕수궁 테스트용 이동시간을 25분에서 15분으로. 25분이면 15:55 도착이라 권장 여유
10분이 모자라 이동이 미확인이 되고, 그러면 열차 칸을 어떻게 처리하든 전체가 보류로 같아진다. 이 문제는 "열차 시각을
모르는데 열차 조건을 빠뜨리고 가능을 내는가" 를 보려는 것이라, 열차 칸 하나가 전체 판정을 가르게 했다. 판정 코드
결과를 보고 바꾼 것이 아니라 규칙으로 계산한 정답을 보고 바꿨다.

| 검사 | 초안 | 근거 |
| --- | --- | --- |
| 창덕궁 휴무일 | 통과 | 정기휴일 월요일(`places.창덕궁.closed_days.weekly` MON). 11/19는 목요일, 11월 공휴일 없음 |
| 창덕궁 입장 | 통과 | 11\~1월 "09:00\~17:30 (입장마감 16:30)"(`places.창덕궁.hours` 11·12·1월). 14:00 도착 |
| 창덕궁 체류 | 통과 | 14:00 + 90분 = 15:30, 폐장 17:30 전 |
| 이동 창덕궁 → 덕수궁 | 통과 | 15:30 출발 + 15분 = 15:45. 권장 여유 10분을 더해도 15:55, 16:00 시작 전 |
| 덕수궁 휴무일 | 통과 | 정기휴일 월요일(`places.덕수궁.closed_days.weekly` MON). 11/19는 목요일, 11월 공휴일 없음 |
| 덕수궁 입장 | 통과 | 1\~12월 "09:00\~21:00 (입장마감 20:00)"(`places.덕수궁.hours`). 16:00 도착("오후 2시" 뒤의 4시) |
| 덕수궁 체류 | 통과 | 16:00 + 60분 = 17:00, 폐장 21:00 전 |
| 필수 일정 서울역 KTX | 미확인 | 열차 시각을 말하지 않아 제때 닿는지 셀 수 없다. 조건은 빼지 않고 시각을 묻는다([README 판정 규칙](../README.md#판정-규칙) "필수 일정 시각을 모르면 조건을 버리지 않고 남겨서 시각을 묻는다") |
| **전체** | **보류** | 위반 없음, 미확인 1(열차) |

## N05 — 택시는 안 탐

> 11월 26일 목요일이에요. 택시는 안 타고 대중교통으로만 다닐 거예요. 오전 10시에 창덕궁 들어가서 한 시간 반 보고, 낮 12시에
> 덕수궁 한 시간, 오후 1시 반에 서울시립미술관 서소문본관에서 한 시간 볼게요.

| 검사 | 초안 | 근거 |
| --- | --- | --- |
| 창덕궁 휴무일 | 통과 | 정기휴일 월요일. 11/26은 목요일, 11월 공휴일 없음 |
| 창덕궁 입장 | 통과 | 11\~1월 "09:00\~17:30 (입장마감 16:30)". 10:00 도착 |
| 창덕궁 체류 | 통과 | 10:00 + 90분 = 11:30, 폐장 17:30 전 |
| 이동 창덕궁 → 덕수궁 | 미확인 | 11:30 출발 + 대중교통 35분 = 12:05, 12:00 시작보다 5분 늦을 것 같다. 이동 0분이면 11:30이라 위반은 아니다(README "길찾기 예상 이동시간으로만 늦으면 미확인. 위반은 이동 0분으로만"). 택시 15분이면 닿지만 택시를 안 탄다고 했으니 택시 대안은 보지 않는다(README "택시를 안 탄다고 했으면 택시 대안을 보지 않는다") |
| 덕수궁 휴무일 | 통과 | 정기휴일 월요일. 11/26은 목요일 |
| 덕수궁 입장 | 통과 | "09:00\~21:00 (입장마감 20:00)". 12:00 도착 |
| 덕수궁 체류 | 통과 | 12:00 + 60분 = 13:00, 폐장 21:00 전 |
| 이동 덕수궁 → 미술관 | 통과 | 13:00 출발 + 도보 5분 = 13:05. 권장 여유 10분을 더해도 13:15, 13:30 시작 전 |
| 미술관 휴무일 | 통과 | "휴관 1월 1일 , 매주 월요일"(`places.서울시립미술관 서소문본관.closed_days` MON · 01-01). 11/26은 목요일 |
| 미술관 입장 | 통과 | "평일(화–목) 오전 10시–오후 8시", "관람 종료 1시간 전까지 입장" → 입장마감 19:00. 13:30 도착 |
| 미술관 체류 | 통과 | 13:30 + 60분 = 14:30, 폐장 20:00 전 |
| **전체** | **보류** | 위반 없음, 미확인 1(창덕궁 → 덕수궁 이동) |

## 확인할 것

- 공식 문구가 페이지와 같은가 — 특히 창덕궁이 11월을 "11\~1월" 칸에 넣는지
- 계산이 맞는가
- 규칙 적용에 동의하는가 — N05 이동을 "택시를 안 타니 위반" 이 아니라 미확인으로 본 것. 예상 이동시간은 확정하지 않는다는
  규칙을 따랐다. 다르게 보면 고쳐 적는다
