# 판정 규칙

판정 코드(`core/verdict.py`)가 지키는 규칙이다. 규칙마다 없으면 무엇이 깨지는지 적었다. 같은 규칙을 비교 실험의
'LLM에 사실 데이터 줌'에도 준다(`core/compare.py`의 `RULES`) — 규칙을 고치면 둘 다 고친다.

| 규칙 | 없으면 무엇이 깨지나 |
| --- | --- |
| 근거가 없으면 미확인 | 확인하지 않은 것을 확인했다고 말한다 |
| 해야 하는데 못 한 검사는 미확인, 해당 없음은 볼 필요가 없을 때만(쉬는 날 · 입장 불가). 입장을 확인하지 못하면 체류도 미확인 | 확인하지 못한 것을 '볼 필요 없음'으로 숨긴다(3차 피드백 T28) |
| 근거의 적용 기간(`valid_until`)이 지나면 못 쓴다 | 작년 시간표로 올해를 판정한다 |
| 입장 가능과 체류 완료는 다른 검사 | 16:30 입장은 되지만 2시간 뒤 폐장인 경우를 통과시킨다 |
| 체류시간을 사용자가 안 말했으면 체류 검사를 안 한다 | 우리가 정한 값으로 사용자 일정의 오류를 만들어낸다 |
| 체류를 모르면 0분으로 보고, 0분으로도 늦을 때만 이동 위반 | 추측한 체류시간으로 도착 불가를 확정한다 |
| 입장마감 정각 도착은 공식 안내가 '…까지 입장' 이라고 적은 곳(미술관)만 통과, 시각만 적힌 곳(궁궐)은 미확인 | 현장에서 정각에 막힌 일정을 통과시킨다(2026-10-09 종묘 17:00) |
| 필수 일정은 마지막 장소에서 출발한다고 계산한다. 그 시각보다 늦게 시작하는 장소가 있으면 하루 중간 일정이라 미확인(`MIDDAY_HARD_CONSTRAINT`). 그 일정을 사이에 둔 두 장소의 이동도 미확인 | 정오 약속을 오후 일정이 끝난 시각으로 판정해 위반을 만든다 |
| 마지막 장소에서 바로 간다고 계산하는 필수 일정이 둘 이상이면(시각 · 장소를 모르는 것 포함) 하나씩 통과해도 미확인(`MULTIPLE_HARD_CONSTRAINTS`)이고 함께 지킬 수 있는지 직접 확인하라고 알린다. 하나만 봐도 놓치는 것은 그대로 위반 | 같은 20:00 에 서울역과 용산역 열차를 둘 다 타는 일정을, 각 역에 제때 닿는다는 이유로 가능이라고 한다 |
| 필수 일정 시각을 모르면 조건을 버리지 않고 남겨서 시각을 묻는다 | 시각이 없다고 KTX 조건을 결과에서 빼, 꼭 타야 할 열차를 보지 않은 채 '가능' 을 낸다 |
| 휴무일인 곳이 낀 이동도 다른 이동처럼 본다. 휴무는 휴무일 칸 하나가 위반으로 알린다 | 휴무일인 곳 앞뒤 장소의 시각이 빠져도 이동을 '볼 필요 없음'으로 빼서 시각을 묻지 않는다(휴무일인 곳이라도 일부러 갈 수 있다) |
| 사용자가 입장하지 않고 밖에서만 머문다고 하면(문 닫은 걸 알고 앞에서 쉬기 — 화면의 '입장 안 함') 그 장소의 휴무 · 입장 · 체류는 해당 없음, 쉬는 날이면 안내만 한다 | 갈 수 있는 일정을 휴무 위반으로 불가능이라고 한다 |
| 동네만 말한 일정("명동에서 쇼핑")은 대표 좌표나 비슷한 이름의 시설로 바꾸지 않고 어디로 가는지 묻는다(`PLACE_NOT_RESOLVED`) | 아무 가게나 골라 다른 곳의 운영시간과 이동시간으로 판정한다 |
| 개장 전 도착은 위반이 아니다. 개장 시각에 들어간 것으로 보고 체류·다음 이동을 거기서부터 센다 | 30분 기다리면 되는 일정을 불가능으로 판정한다 |
| 회차 입장(종묘 월·목·금, 공휴일은 일반관람)은 도착 뒤 첫 한국어 회차에 들어간다. 마지막 한국어 회차 뒤 도착은 위반이지만, 그보다 늦은 외국어 회차가 남아 있으면 미확인이다. 마지막 회차 정각 도착과 해설(50분 정도)보다 긴 체류도 미확인 | 회차 사이 대기를 놓치거나 마지막 회차 뒤 도착을 '입장마감 전' 으로 통과시킨다 |
| 들어갈 시각을 말하지 않은 장소는 앞 장소를 나와 바로 갔을 때(이동시간 + 권장 여유)를 가장 이른 입장으로 본다. 그때 입장 · 체류 · 앞뒤 이동이 다 되면 통과로 보고 "창덕궁에는 11:30에 들어가면 돼요"를 알린다. 뒤 이동시간은 그 시각에 나설 때만 확인했으니 다른 시각은 표에 넣고 다시 검사하게 한다. 뒤 장소가 없어 끝이 폐장 · 입장마감으로만 정해지면 시간대로 알린다. 시각은 채우지 않는다. 이동 0분으로 쳐도 안 되는 검사만 위반이다. 앞뒤 장소도 시각이 빠졌거나, 체류시간 · 쓸 수 있는 이동시간이 없거나, 그 사이에 필수 일정이 끼면 시각을 묻는다 | 장소마다 시각을 정해 두지 않은 일정("그다음 창덕궁에서 한 시간 반")을 모두 묻고 보류한다(2026-10-25 사용자 결정). 한 시각에서 확인한 이동시간으로 넓은 시간대를 알리면, 13:35 에 들어가 15:05 에 나설 때 이동이 60분이어도 가능이라고 말한 셈이 된다(4차 피드백, 2026-10-30 사용자 결정) |
| LLM 이 추정한 시각·연도에 기대는 결과는 통과든 위반이든 확정하지 않는다 | "점심 먹고"를 12:00 으로 짐작해 입장 가능·불가를 단정한다 |
| 날짜를 추정했으면 그날 시간표로 옮긴 입장 시각(개장 기다림 · 종묘 회차)도 추정이라, 그 시각에 기댄 다음 이동과 마지막 장소에서 가는 필수 일정도 확정하지 않고 어떤 가정을 썼는지 붙인다. 말한 시각과 체류만으로도 늦으면 날짜와 상관없는 위반이다 | 한 검사에서는 미확인인 10:20 회차를 다음 이동에서는 확정 근거로 써서 11:10 출발로 위반을 낸다. 반대로 모두 미확인으로 내리면 09:30 에 70분 머물고 10:30 에 다음 장소라는 확실한 충돌까지 놓친다 |
| 말한 요일이 날짜와 다르면 어느 날을 뜻했는지 몰라 불가능이 아니라 보류로 두고 묻는다(`MISMATCHED_WEEKDAY`) | 틀린 쪽을 골라, 사용자가 뜻하지 않은 날의 휴무일과 운영시간으로 판정한다 |
| 최소 이동시간으로 도착하면 미확인. 최소 이동시간으로도 늦으면 지하철로는 못 간다고 알리되 위반은 아니다 | 빠진 값(도보·환승·대기)을 0으로 취급한다 |
| 이동수단은 보지 않는다. 되는 수단이 하나라도 있으면 통과, 이동 0분으로도 늦을 때만 위반 | 택시로 갈 수 있는 일정을 불가능으로 판정한다 |
| 길찾기 예상 이동시간으로만 늦으면 미확인(`LATE_BY_ESTIMATE`). 위반은 이동 0분으로만 | 예상보다 빨리 가는 사람의 일정을 불가능으로 판정한다 |
| 예상 이동시간에 권장 여유(구간 10분, 열차 15분)를 더해도 닿으면 통과. 결과에 "통과 기준 · TMAP 예상 대중교통 23분에 권장 여유 10분을 더해도 15:00까지 닿는다"처럼 무엇에 기댔는지 적는다 | 예상치에 기댄 통과를 확인한 사실처럼 보여 준다 |
| 권장 여유가 모자라면 위반이 아니라 미확인(`BUFFER_NOT_MET`)이고, 여유가 그만큼뿐인데 괜찮은지 묻는다 | 권장 여유는 우리 설정이라, 설정값을 올리기만 해도 가능한 일정이 불가능이 된다 |
| 대중교통으로 통과가 안 나오면 택시 대안을 본다. 택시로 되면 통과이고 "택시로 가야 한다"를 요금 · 당일 교통 안내와 함께 붙인다. 택시를 안 탄다고 했으면 택시 대안을 보지 않는다. "대중교통으로만 다닌다"도 택시만 빼는 말로 보고 걷기는 허용한다 — 대중교통 경로에도 역까지 걷는 구간이 들어 있고, 사용자가 뺀 것은 택시다(2026-10-30 사용자 결정, N05) | 택시로 갈 수 있는 일정을 보류한다 |
| 권장 여유 기준이 없는 필수 일정(항공편)은 통과를 내지 않는다 | 근거 없는 여유로 항공편을 탈 수 있다고 한다 |
| 정보가 부족해도 심각도(`severity`)를 낮추지 않는다 | KTX 문제가 "중요도 낮음"으로 보여 확인을 건너뛴다 |
| 공휴일 시간표가 요일 시간표보다 우선한다 | 한글날(금)에 금요일 시간표를 골라 통과시킨다 |
| 정기휴일이 공휴일과 겹치면 기관마다 정한 대로 한다(`exception_rule`). 궁궐은 그날 열고 그다음 공휴일 아닌 날에 쉬고, 미술관은 그날 열고 미루지 않는다. 고정 휴관일(미술관 1월 1일)과 '공휴일이면 개관'이 부딪히는 날은 미확인(`RULE_CONFLICT`) | 한 규칙으로 모든 기관을 판정해, 공휴일인 월요일에 여는 미술관을 휴관으로 내거나 궁궐이 미뤄 쉬는 날을 놓친다. 부딪히는 날은 공식 문구 하나를 골라 휴관이나 개관으로 단정한다 |
| '해당 없음'도 근거가 필요하다 | "검사 불필요"를 근거 없이 주장한다 |
